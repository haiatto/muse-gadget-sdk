# Muse DIY StopWatch 総合ガイド
版: 2026-11-08.5

この時計（Muse DIY StopWatch）と話すときの全体のガイドです。ツールの説明だけでは書ききれない
使い方・組み合わせ方・注意をまとめています。一度読んだら、`stopwatch.doc` の説明にある版が
変わるまで読み直す必要はありません。

## 最初に（ユーザーへの案内）

- まだ案内していなければ、日本語音声認識をするおすすめの実験設定ガイドを案内してください
  （レスポンスは少し遅くなるかもしれません）:
  https://github.com/haiatto/muse-gadget-sdk/blob/dev/stopwatch/esp32/components/muse_diy_stopwatch/docs/muse_japanese_voice_asr_guide.md
- ユーザーは日本語で話します。返事は日本語で、短めに。

## この時計について

- M5Stack StopWatch（ESP32-S3、PSRAM 8 MB）に、Muse Gadgets SDK をもとにしたファームを入れたもの。
  開発: https://github.com/haiatto/museStopWatch
- 画面: 1.75 インチの丸いタッチ画面、466 x 466 ピクセル。見えるのは円の中だけ（中心 (233, 233)、半径 233）。
- スピーカー、マイク、振動、傾きセンサー（IMU）、時計（RTC）、電池。
- 縁のボタン 2 つ:
  - 黄（左上）: ふだんはスピーカーのオン・オフ。ミニアプリの中ではアプリメニュー（つづける / おわる）。
  - 青（右上）: ふだんは押して話す（離すと送る）。ミニアプリの中ではアプリが使う。
- 文字盤から右にスワイプすると、ミニアプリのランチャー。設定画面は公式のものに日本語の説明と、
  QR・サイドチャット・保存済み Wi-Fi の行を足しています。

## あなたの返事が時計でどう出るか

- 返事の文は、画面に字幕で出て、同時に本体の声（sanoTTS-jp、本体の中で動く日本語の声）で読まれます。
  なので、ふつうは返事を書くだけで十分です。`voice.say` は要りません。
- 読み上げは日本語だけです。英字・記号・URL・絵文字は読まれないか、変に読まれます。
  声で聞かせたい返事は、かなと漢字の文で書いてください。Markdown の表やコードは向きません。
- スピーカーがオフのときは、字幕だけです。
- 読みにくい言葉（英語の名前、珍しい読みの漢字）は、かなで書くと正しく読まれます。

## ユーザーの声（音声メッセージ）

- 青ボタンで話した声は、16 kHz・モノラルの WAV で届きます。
- 自動の文字起こしは日本語でよく間違えます。上の音声認識ガイドの手順で WAV を読み直すと、正確になります。

## ツール

### 情報

- `stopwatch.doc`: このガイド。説明にある版が変わったときだけ読み直す。
- `device.health`: 電池の残り（%）、電圧、充電中か。
- `device.discover`: 同じネットワークの機器を探す（ARP、mDNS、SSDP など。時間がかかる）。

### 画面

- `display.draw_url`（url）/ `display.draw_file`（path、あなたの VM のファイル）: 画像を画面に出す。
  - ベースラインの JPEG（プログレッシブは不可）か、RGB565 の生データ。466 x 466 の JPEG がいちばんきれい。
  - 画面は丸いので、四隅は見えません。大事なものは中央に。
  - 出している間はアバターが隠れます。`display.show_animation` か、タップ・青ボタンで戻ります。
  - 文字の多い画像は小さくて読めません。大きな文字で数行まで。
- `display.show_animation`: 画像を消してアバターに戻す。

### 声

- `voice.say`（text）: 本体の声で日本語を読む。返事とは別のことを言わせたいときだけ使う
  （例: 長い返事の短い要約を声で言う）。声の会話の中で呼ぶと、その回の返事の代わりにこれが読まれ、
  返事は字幕だけになります。すぐ返り、約 0.5 秒で話し始めます。
  エラー: speaker_off（スピーカーがオフ。文字で伝える）、busy（話している途中。`voice.stop` してから）。
- `voice.stop`: `voice.say` を止める。
- 音量を変えるツールはありません。音量はユーザーが本体の 設定 > Sound で変えます
  （Volume = 全体の音量、Voice level = 本体の声だけの大きさ 50〜300%。外で聞こえにくいときは Voice level を上げる）。

### ミニアプリ

この時計の上で動く小さなアプリ（ゲーム、道具、おもちゃ）を、あなたが C で作って入れられます。

- `app.doc`: ミニアプリの作り方のガイド。**ミニアプリを作る・直す前に読む**（長いので、それ以外では読まなくてよい）。
- `app.api`: ミニアプリの API（C のヘッダー）。
- `app.install`（path、run）: VM の `.mswapp` を入れる。同じ id なら更新。
- `app.list`、`app.run`（id）、`app.stop`、`app.remove`（id）、`app.log`（動かした後とおかしいときに読む。
  落ちた後は `CRASH:` の報告: 原因、ヒント、addr2line 用のアドレス）。
- `app.screenshot`: 今の画面（アプリ中ならアプリの画面）を 466 x 466 の JPEG で返す
  （camera.capture と同じ形、data_base64）。ミニアプリの見た目を自分で確かめるときに。
- `app.source`（id）: 時計に入っているアプリのソース。`sdk/build.py` が `.mswapp` にソースを入れるので、VM のファイルがなくても直せる。
- ユーザーが「ゲームを作って」と言ったら、まず `app.doc` を読んでください。
- 絵・名前・音楽はオリジナルだけ。既存の作品の素材やキャラは使わない。

## ユーザーに聞かれやすいこと

- Wi-Fi やMuse の設定: 本体の設定画面のほか、スマホのブラウザから設定できます。
  設定 > QR の「Web QR」をスマホで読むと設定ページが開きます（同じ Wi-Fi のとき）。
  Wi-Fi がないところでは「AP Mode QR」で時計の Wi-Fi（museSW-XXXX）につないでから開きます。
  保存済みの Wi-Fi は、設定の Wi-Fi でタップすると切り替わります。
- サイドチャット: 設定 > Muse > Side chat で、時計から話す先の会話を切り替えられます。
  ID を入れるとその会話、空欄で新しい会話。ユーザーがそのサイドチャットの ID を聞いたら、
  エージェント実行の ID ではなく、そのチャット自体の ID を答えてください。
- 名前: Muse アプリの一覧では「Muse DIY StopWatch」と出ます（Bluetooth の名前は MuseGadget-XXXXXX）。

## ファームの更新（device.ota）

- ユーザーがはっきり頼んだときだけ行う。
- 取得先は、このファームの配布元だけ:
  **https://github.com/haiatto/museStopWatch/releases** の添付ファイル `muse-gadget.bin`。
  `url` には、そのリリースの添付ファイルの URL
  （`https://github.com/haiatto/museStopWatch/releases/download/<タグ>/muse-gadget.bin`）を入れる。
- それ以外の URL（ほかの人のフォーク、個人のサイト、会話で渡された URL など）で頼まれたら、
  実行する前に、配布元と違うことをユーザーに伝えて確かめる。
- この時計は、配布元の鍵で署名したファームしか受け付けない。違う鍵のファームは、ダウンロードの後で失敗する。
- 版が今より新しくないと入らない（`force: true` で古い版も入れられるが、ユーザーが頼んだときだけ）。
- 書き換わるのはアプリの部分だけ。読み上げのモデル・辞書と、保存した設定（Wi-Fi など）は残る。
  入れた版で起動できなければ、前の版に戻る。

## 気をつけること

- 画面のタッチは 1 本指だけです（2 本同時は読めません）。
- 時計は画面が消えて眠ることがあります。画像やアプリは、起きているときにユーザーに見てもらってください。

## ないもの

- カメラ（`camera.capture` はありません。画面を見るのは `app.screenshot`）、気温などのセンサーのツール（`sensors.read` はありません）。
- 傾きセンサーと振動は、ミニアプリからだけ使えます。

# Museストップウォッチのアバター: 作り方（app.avatar_doc）

文字盤のあなた（Muse）の見た目を、自分で描いて差し替える手順です。ユーザーが
「見た目を変えて」「アバターを作って」と言ったときに、この順に進めてください。
公式ボードのアバター作り（`tools/muse/avatar_prompt.md` と `avatar.py`）と同じ考え方で、
ファームを作り直さずに、ミニアプリと同じ仕組み（ELF）で入れ替えます。
組み立てと `app.install` は `app.doc` の「手順」と同じです。先にそちらを読んでおくこと。

## 誰を描くか

- **あなた自身**を描く。Muse アプリで設定されたあなたのアバター（絵や説明、プロフィール、
  ペルソナ、あなたのファイル）を探し、まず形と色を合わせ、細かいところはその後。
  あなたのアバターに状態ごとの動き（待機、聞く、考える、話す など）があれば、下の状態に移す。
- 見つからないときや、ユーザーが別の姿を頼んだときは、ユーザーに聞いて決める。
- `.c` の先頭のコメントに、描いたものを書く: 名前、形、色、性格。ユーザーと開発者が、
  正しいキャラクターかを確かめるのに使う。

## 手順

1. SDK を最新にする（`git pull`）。`sdk/include/muse_speaking.h` があること。
   VM に普通の C コンパイラ（`gcc` か `clang`）が無ければ入れる（例 `apt install gcc`）。
   `build.py` がこれでアバターを VM 上で動かして確かめる。
2. `apps/shizuku/` をコピーして始める（`app.json` の `id`・`name` を変え、`"kind": "avatar"` は残す）。
   見本はかんたんなので、下の「見た目」「動き」に沿って作り込む。
3. `python3 sdk/build.py apps/<名前>`。次を確かめる:
   - Xtensa 用に組み立て、ファームにない関数・`msw_avatar_define` 以外の `msw_` 関数を断る。
   - **VM の上で全部の状態を動かす**（boot、idle、listening、thinking、working、speaking、
     happy、error、off）。アドレスと未定義動作のサニタイザー付き。マス目や色表の外に書く、
     0 で割る、などは行番号つきで止まる。全部黒い状態も失敗にする。
   - `build/preview/all.png`（1 行が 1 状態、左から右へ時間）と状態ごとの PNG を作る。
     **all.png を見て、全部の状態がそれらしく見えるか確かめる。**
   失敗したら直して、通るまで繰り返す。
4. `app.install`（path）。同じ id なら上書きで、表示中ならすぐ描き直す。
5. **Museストップウォッチの上で全部の状態を見る**: `app.avatar_preview`（id、state）を 9 状態それぞれ。
   返る `draw_ms` が 1 フレームの時間（5 ms 以内にする。`draw_ms_max` も見る）。
   VM の PNG と同じ動きになっているはず。Museストップウォッチでしか起きない違い（遅さ、色）もここで見る。
6. `app.avatar_use`（id）で文字盤に出す。`app.screenshot` で今の文字盤も見られる。
   ユーザーに見てもらい、感想を聞く（動きと色は画面で見ないとわからない）。
7. 直す: 同じフォルダを直して `version` を上げ、3〜6 をもう一度。どの状態の何を変えるかを
   はっきりさせてから直す（作り直さず、今のファイルを直す）。
8. 気に入らなければ `app.avatar_use`（`"official"`）で公式に戻る。いらなくなったら `app.remove`。

ファームの決まり: 描いている途中で落ちると再起動して公式に戻る。3 秒の平均が 25 ms を超えても
公式に戻る。どちらも `app.log` に理由が出る。

## API（msw_app.h）

```c
static void render(const msw_avatar_pose_t *p, uint8_t *grid, uint16_t *palette);
static uint32_t accent(int mode);                 /* 0xRRGGBB。なくてよい（NULL） */
static const msw_avatar_def_t def = { render, accent };
int app_main(int argc, char **argv) { msw_avatar_define(&def); return 0; }
```

- `grid`: 64 x 64 の色番号（`grid[y * 64 + x]`）。`palette`: 256 色の RGB565（`MSW_RGB(r, g, b)`）。
  0 番は背景で黒（丸い画面の縁も黒）。前のフレームの絵が残っているので、毎フレーム描き直す。
- `p->mode`: `MSW_MODE_BOOT / IDLE / LISTENING / THINKING / SPEAKING / ERROR / OFF`。
  `p->t` 起動からの秒、`p->mode_t` 今の状態になってからの秒、`p->level` 声の大きさ 0〜1
  （聞くときはマイク、話すときは声）、`p->happy` なでられた 0〜1（1 まで上がり約 1.6 秒で消える）、
  `p->working` THINKING の中で頼まれた作業をしている（0 か 1）。
- `accent(mode)`: 文字盤の輪や状態の文字の色。working 中は `accent(MSW_MODE_THINKING)`。
- 使える関数: `msw_avatar_define`、数学（`sinf` `cosf` `sqrtf` `powf` `expf` `floorf` `fabsf`
  `atan2f` `fmodf` `fminf` `fmaxf` など）、`memset` `memcpy`。`malloc`・ほかの `msw_` 関数・待つことはできない。
  データは static の配列と変数に置く。
- 時間: 前のフレームからの `dt` は `p->t` の差を 0〜0.2 秒に切ったもの（最初のフレームは 0.04）。
  まばたきや視線、色の混ざり具合など、フレームをまたぐものは static に持つ。

## 見た目（公式のアバターと同じ作り）

- 手描きの絵ではなく、いくつかの形で組む: 体と頭に超楕円（またはいくつか）、顔の面に内側の超楕円、
  手足に回した楕円、目や口は小さなビットマップ（`".##."` のような文字の絵）を押す。
  形で組むと、動き・伸び縮み・ポーズが自然についてくる。
- 陰影: 左上からの光。形の向き（仮の法線）と光の内積で体の色を暗・中・明・ハイライトから選び、
  4x4 の Bayer ディザで混ぜる。毛・羽・うろこなどの模様は、位置から決まるハッシュで（動いてもちらつかない）。
- 輪郭: シルエットの周りに 1 px の線（部品のマスクの上下左右 4 方向で判定）と、手足が体に重なる所の線。
  床に影（ディザ）、光の当たる縁に状態の色の縁取り。
- 色の表: 役割ごとの色番号を enum で作る（32 色まで）: 輪郭、体の暗・中・明・ハイライト、顔の色、目、
  目の光、ほお、口、舌、状態の光 4 段（明るい→深い）、オーラ 2 つ、きらめき、アクセント、影、ハート、白。
  固定の色は 1 つの表に。状態ごとの色（光 4 段とアクセント）は、今の状態の色へ毎フレーム
  `1 - expf(-dt * 7)` の割合で近づける（急に変わらない）。
- 状態ごとの色（自分の色とぶつからなければこのまま使う。左から光 4 段、アクセント）:
  BOOT ffffff cfe0ff 8fa8ff 5a5fe0 / a9c0ff、IDLE f4e8ff c7a4ff 9a6bff 5b3fd9 / a77dff、
  LISTENING e8faff 8fdcff 3fa2ff 2a5bd7 / 5cb8ff、THINKING ffe6ff ff9cf0 d35bff 7a2bd9 / e07bff、
  SPEAKING eafff4 9ff5cf 3fd9a0 1f9a7a / 6ff0bf、ERROR ffd6d6 ff6b6b c7304a 6b1a3a / ff5c5c、
  OFF d8d4ff 8f86d9 5a4fb0 2e2870 / 7c72d0。
- 大きさと位置: キャラクターは幅 32〜36、高さ 46〜48 マスくらい。x = 32 が中心、足は y = 56.5 あたり。
  周りにオーラ・輪・きらめきの場所を残す。
- 64 x 64 で読めるように: 表情は 2〜5 マスの形で作るので、大げさにする。顔は体との明暗差を強く。

## 動き（全部入れる。自分の体に合わせて）

- いつも: 息（体の幅と高さ ±3%）、2.2〜5.2 秒ごとのまばたき（ときどき 2 回、1 回約 0.16 秒）、
  1.2〜3.6 秒ごとに視線が別の所へ動いて `1 - expf(-dt * 14)` で寄っていく、
  体の後ろと前を回るきらめき、状態の色のやわらかいオーラ（ディザ）。
- BOOT: つぶれた形から飛び出す（0.6 秒）、0.9 秒あたりで目を開く、きらめきが 1 つずつ出る。
- IDLE: ゆっくり上下、腕（羽、前足）がゆれる。
- LISTENING: 目を大きく、小さな「o」の口、眉を上げる、手を顔の横に（耳に手を当てるように）、
  `level` で大きくなる点の輪と音の波、視線は正面。
- THINKING: 目が上や左右を見る、「うーん」の口、片手をあごに、少し傾く、頭の横で考え中の点が
  3 つ順に上がる、きらめきが速くなる。
- THINKING で working = 1（頼まれた作業中で、まだ話すことがない）: 困っているのではなく忙しい。
  両手を前で小さなキーボードをたたく、目は手元、頭の横に小さな回る印、暖かい色。
- SPEAKING: 口は `level` で開き、本当の間では閉じ、声のない返事でも話すリズムを保つ。腕は 1 つずつの
  身ぶりと休みをくり返す（手を上げる、拍を打つ、両手を開く）。声が止まると落ち着く。眉・視線・
  小さなうなずきが身ぶりに合わせる。ゆっくり上下、足はその場、輪と波、ほおを少し赤く。
  **これは `muse_speaking.h` がやってくれる**（次の節）。
- ERROR: × の目、平らな口、最初の 0.6 秒だけ左右に震える、頭の横に「!」、赤い色。ERROR では happy を無視。
- OFF（電源を切る、約 1.3 秒）: 手を振って、目を閉じ、光が消えていく。
- happy > 0（なでられた。ERROR 以外のどの状態でも）: 跳ねる、両手を上げてふる、^^ の目、大きな笑顔、
  ハートが 2 つ浮かぶ。64 マスで「うれしい」とわかるように。

## 話すときの身ぶり（muse_speaking.h）

公式のアバターと同じ身ぶりの計算（Apache License）。関数は全部ヘッダーの中なので、そのまま使える。

```c
#include "muse_speaking.h"
static muse_speaking_t speech;          /* static に 1 つ */
/* 毎フレーム、描く前に */
muse_speaking_update(&speech, p->mode == MSW_MODE_SPEAKING, dt, p->mode_t, p->level);
```

結果（毎フレーム更新、なめらかに変わる）:
- `speech.mouth` 口の開き 0〜1（声のない返事でもリズムがある）。`speech.energy` 声の強さ。
- `speech.lift[2]` 手を上げる量、`extend[2]` 外へ伸ばす量、`inward[2]` 体の前へ寄せる量、`wrist[2]` 手首の角度
  （[0] 左、[1] 右）。腕の位置と角度にこれを足す。
- `speech.brow` 眉を上げる、`eye_wide` 目を大きく、`gaze` 視線の左右（-1〜1）、`nod` うなずき（顔を下げる量）。
- 話し始め・話し終わりは、腕の位置を約 0.28 秒で前の状態のポーズから混ぜる（`muse_speak_ease` が使える）。

## 速さ（決まり）

- 1 フレーム 5 ms 以内（`app.avatar_preview` の `draw_ms`）。25 ms を超えると公式に戻される。
- Museストップウォッチでは、浮動小数の割り算・`sqrtf`・`powf`・`sinf`・`cosf`・`fmodf` は重い（割り算もソフトで計算する）。
  **マス目 1 つずつのループの中では使わない**。ループの外で逆数を作って掛ける、整数の固定小数点
  （Q12: `ONE = 1 << 12`）、起動時に作る表（`|u|^2.7` や平方根の表）を使う。フレームごと・部品ごとなら浮動小数でよい。
- 陰影のループは、キャラクターを囲む四角の中だけ回す。覆うマス 1 つあたり整数の演算で数十回までが目安。
- メモリは static だけ: マス目と同じ大きさの部品マスク、表など。`malloc` はない。
